# AGENTS.md

Start here before making any change in this repository:

1. Read `docs/AI-context.md` in full.
2. Treat `docs/AI-context.md` as the canonical index for repository rules, architecture, and documentation flow.
3. Read `README.md` before changing runtime architecture, local workflows, or product assumptions.
4. Review the relevant document in `docs/features/` before editing a specific area.
5. Use `docs/waves/` by default for feature work, multi-agent execution, parallel ownership, or any change that needs a staged plan.
6. If you resolve an architecture bug, document it in `docs/architecture/fixes/`.
7. If you resolve a non-architectural but reusable bug, incident, workaround, or debugging lesson, document it in `docs/learning-log/`.

If documentation conflicts, follow the most specific document for the area you are changing, while keeping `docs/AI-context.md` aligned.
