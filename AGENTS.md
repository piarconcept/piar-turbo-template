# AGENTS.md

Start here before making any change in this repository:

1. Read `docs/AI-context.md` in full.
2. Treat `docs/AI-context.md` as the canonical index for repository rules, architecture, and documentation flow.
3. Read `docs/concept/initial-questions/README.md` and ask unanswered required questions before initializing a new product, replacing template identity, choosing apps, changing database configuration, or starting product feature work.
4. Read `README.md` before changing runtime architecture, local workflows, or product assumptions.
5. Review the relevant document in `docs/features/` before editing a specific area.
6. Use `docs/waves/` by default for feature work, multi-agent execution, parallel ownership, or any change that needs a staged plan.
7. If you resolve an architecture bug, document it in `docs/architecture/fixes/`.
8. If you resolve a non-architectural but reusable bug, incident, workaround, or debugging lesson, document it in `docs/learning-log/`.

If documentation conflicts, follow the most specific document for the area you are changing, while keeping `docs/AI-context.md` aligned.
